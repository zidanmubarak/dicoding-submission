# Machine Learning Terapan

Ini adalah direktori untuk submission pada kelas **Machine Learning Terapan** di Dicoding Academy. Proyek akhir ini berfokus pada pembangunan **Sistem Rekomendasi Destinasi Wisata di Indonesia** dengan menerapkan dua pendekatan utama, yaitu *Content-Based Filtering* dan *Collaborative Filtering*.

## Kriteria yang Telah Dipenuhi
- [x] Mengirimkan 3 berkas utama: Laporan Proyek (.md), Script Python (.py), dan Jupyter Notebook (.ipynb) yang sudah dijalankan.
- [x] Dokumentasi lengkap pada setiap cell code menggunakan text cell pada notebook.
- [x] Menerapkan dua pendekatan solusi: Content-based Filtering & Collaborative Filtering.
- [x] Memenuhi seluruh rubrik penilaian laporan: Project Overview, Business Understanding, Data Understanding, Data Preparation, Modeling and Results, Evaluation, dan Struktur Laporan.
- [x] Menerapkan seluruh kriteria tambahan pada laporan (Solution Approach ganda, visualisasi data mendalam, evaluasi formula metrik, dsb).

## Struktur Direktori
- `submission/` : Berisi berkas proyek submission:
  - `README.md` : Laporan lengkap proyek machine learning sistem rekomendasi tempat wisata.
  - `sistem_rekomendasi.ipynb` : Jupyter Notebook implementasi menyeluruh (EDA, Data Preparation, Modeling CBF & CF, Evaluasi).
  - `sistem_rekomendasi.py` : Script Python dari sistem rekomendasi yang dibangun.
  - `tempat_wisata_indonesia.csv` : Dataset destinasi wisata Indonesia yang digunakan.
  - `assets/` : Gambar grafik dan visualisasi hasil Exploratory Data Analysis (EDA).
- `FEEDBACK.md` : Berisi umpan balik (feedback) dan ulasan lengkap dari reviewer terkait hasil penilaian submission.

Untuk melihat umpan balik dari reviewer Dicoding, silakan buka file [FEEDBACK.md](FEEDBACK.md).
