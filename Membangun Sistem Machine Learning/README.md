# Membangun Sistem Machine Learning

Ini adalah direktori untuk submission pada kelas **Membangun Sistem Machine Learning** di Dicoding Academy. Proyek akhir ini memuat implementasi sistem machine learning secara end-to-end, mulai dari eksperimen dataset, pemodelan & tracking MLflow, otomasi CI/CD workflow, hingga model serving dan sistem monitoring & logging.

## Kriteria yang Telah Dipenuhi
- [x] Melakukan Eksperimen terhadap Dataset Pelatihan
- [x] Membangun Model Machine Learning
- [x] Membuat Workflow CI
- [x] Membuat Sistem Monitoring dan Logging

## Struktur Direktori
- `submission/` : Direktori utama kumpulan file dan repositori submission:
  - `Eksperimen_SML_Zidan-Mubarak.txt` : Tautan repositori GitHub untuk eksperimen dataset pelatihan (Kriteria 1).
  - `Membangun_model/` : Source code, pipeline MLflow tracking, hyperparameter tuning, dan artefak model (Kriteria 2).
  - `Workflow-CI.txt` : Tautan repositori GitHub untuk otomasi CI/CD workflow (Kriteria 3).
  - `Monitoring_dan_Logging/` : Implementasi model serving Docker, konfigurasi Prometheus exporter, dashboard Grafana, dan alerting rules (Kriteria 4).
- `FEEDBACK.md` : Berisi umpan balik (feedback) dan ulasan lengkap dari reviewer terkait hasil penilaian submission.

Untuk melihat umpan balik dari reviewer Dicoding, silakan buka file [FEEDBACK.md](FEEDBACK.md).
